## 先定备案：国内机房和香港机房差的不只是延迟

**如果你的访客主要在中国大陆，买国内机房，走备案；访客在海外或你急着上线，买香港/洛杉矶，跳备案。**

国内服务器对外提供网站服务，ICP 备案是硬性要求，流程是填资料、服务商初审、短信核验、管局审核，一般数个工作日到数周。备案免费，但要等。

真正容易卡住人的，是备案对服务器本身有门槛，很多人买完才发现不满足：

- 必须是**包年包月**，不能是按量付费；
- 购买时长通常**不少于 3 个月**；
- 提交备案期间，服务器**剩余有效期不少于 1 个月**；
- 必须绑定**中国大陆境内的公网 IP**，且**带宽不能为 0**。

所以按“先买一个月试试”的思路买国内机房，再去备案是走不通的，时长不够。反过来，先买 3 个月以上、再提交备案，顺序才对。

免备案的代价不只是延迟。看表格里的带宽列：国内机房是 10M 到 35M 上行、**不限流量**；香港和洛杉矶是 100M 到 500M 大带宽，但**每月 1024GB 流量封顶**。这两种结构适合的站完全不同。国内款适合文字为主、访问量稳定、不想天天盯流量的站；海外款带宽宽，适合图片多、有静态资源分发的站，但一个页面 2MB、每天 2000 次访问，一个月就是 120GB，1TB 并不算多。

还有一层是合规和体验。国内访客访问香港节点，延迟比国内机房高；面向纯国内用户的商业站，长期用海外节点并不合适，行业内普遍的判断也是“能不备案就不备案”只适用于海外业务或临时调试。香港节点更合理的用法是：网站先在香港机器上用 IP 调试好，国内备案同步跑，备案下来再迁回国内机房。

## 再定配置：内存是硬下限，CPU 反而宽裕

**个人博客、作品集：2 核 2G 起步。企业官网、产品展示：2 核 4G 或更高。跑 Node.js、Java、Go 的后端服务：4G 内存起步。**

WordPress、Typecho 这类 PHP 站吃内存的地方在 PHP-FPM 和 MySQL，1 核 1G 能装能跑，但后台装几个插件、开个缓存、再进个 phpMyAdmin，内存就见底，表现为后台转圈、502。2G 是能安心用的下限。2 核 4G 那一档（国内 35 元/月）是企业站和 WooCommerce 的合理区间，商品页、订单、支付流程对内存的峰值要求比静态展示页高得多。

CPU 核数在小站上不是瓶颈，同样 25 元的 2 核 2G 和 35 元的 2 核 4G 之间，优先加内存。

带宽这边，国内款不限流量但上行只有 10M 到 35M，首页图片没压缩、又没接 CDN，几个人同时打开就能感到慢。图片视频多的站，要么选更高带宽档，要么把静态资源丢到对象存储和 CDN 上，后者通常更省钱。

## 买完到上线：四步，别漏端口

**选镜像、放行端口、解析域名、上 HTTPS，按顺序做，半小时能跑起来。**

1. **镜像**：买的时候直接选预装环境，宝塔面板或 WordPress 一键镜像都行。宝塔的好处是后面加站点、改 PHP 版本、配 SSL、备份都在一个界面里；纯小白只想发文章，WordPress 镜像更省事。
2. **防火墙放行端口**：80（HTTP）和 443（HTTPS）必须开；22（SSH）按需，平时可以关；8888 是宝塔面板默认端口，用的时候开，用完关掉或改成不常用端口；3306 是 MySQL，**不要对公网开放**。
3. **域名解析**：在 DNS 服务商加一条 A 记录，主机记录填 `@` 是根域名、填 `www` 是子域名，记录值填服务器的公网 IP。生效通常几分钟到几小时。
4. **HTTPS**：宝塔面板里进“网站 → SSL 证书”，选 Let's Encrypt，勾选域名申请，验证通过后开启“强制 HTTPS”。防火墙的 80 和 443 都要通，否则验证会失败。

HTTPS 现在没有理由不做，浏览器会给 HTTP 站点标“不安全”，搜索引擎收录也受影响。

## 三个最容易踩的坑

**坑一：地域买了不能改。** 云服务器实例创建完成后，通常不支持更换地域。买之前确认清楚访客在哪，国内就选靠近他们的机房，广州、上海一带的节点对华南华东都友好。选错了只能重新买一台再迁数据。

**坑二：按量付费的实例，关机不等于停止计费。** 这是按量付费这类计费模式的通用规则，不是雨云独有的政策：实例停止后计算资源可能仍被保留并继续计费，不再需要应当及时释放，否则账单会一直走。新手最容易犯的错是“先开一台按量的玩玩”，玩完关机放在那。

**坑三：域名解析成功但网站打不开。** 三种可能，按概率排：国内服务器还没完成 ICP 备案，域名访问被拦截；防火墙没放行 80/443；域名解析到的 IP 不是这台机器的公网 IP。备案没下来之前，先用 IP 直接访问调试，或者把站临时放香港节点。
